# 🔐 Cyber-Themed Password Generator

A minimalist yet powerful password generator styled in a dark cyberpunk aesthetic. Built using HTML, Tailwind CSS, and JavaScript, this tool lets users generate passwords of varying strengths—Standard, Mid, and Very Strong—with a single click.

---

## 🚀 Features

- 🔧 **Strength Selection**: Choose from 3 password strength levels:
  - `Standard` (8 characters)
  - `Mid` (12 characters + symbols)
  - `Very Strong` (16+ characters with extended special characters)
- 📋 **Copy to Clipboard**: Easily copy the generated password with one click.
- 🌑 **Dark Tech UI**: Tailwind-powered cyberpunk-themed design.
- 🛡️ **Secure Randomization**: Uses `Math.random()` for character selection (for demonstration only; not cryptographically secure).
